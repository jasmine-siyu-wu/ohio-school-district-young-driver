# Ohio Young Driver Data Explorer

An interactive mapping and data visualization tool for exploring young driver populations, licensing, and transportation safety across Ohio.

## Project overview

This project aims to support geographic analysis of young driver mobility and safety in Ohio. The initial version visualizes school district-level youth population estimates from the U.S. Census Bureau's ACS-ED program.

Future development may incorporate additional indicators, including young driver licensing, driver training, crash involvement, and other transportation safety measures, subject to data availability and disclosure approval.

## Current features

- Interactive Ohio school district map
- Population estimates for ages 15-17, 18-19, and 15-19
- District-level information and geographic comparisons

## Data sources

- U.S. Census Bureau, ACS-ED school district population estimates (2019-2023)
- Ohio school district geographic boundaries (U.S. Census Bureau, 2023)

Specific data vintages and table identifiers will be documented when the source files are finalized.

## Project status

Prototype under development. Population estimates should not be interpreted as licensed-driver counts or licensing rates.
